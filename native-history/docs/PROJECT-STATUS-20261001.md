## 明确缺口与技术债

- 当前新路径无实际设备覆盖：焦点、真实ContentResolver/SAF、配置重建和坏历史撤销。旧包组件成功不代替改动后证据。
- [09-27来源失败表](PLAYBACK-NEXT-PHASE-20260927.md)中的dalvdm/xfdmneo、mgnacg第5线、mutefun第2线及akianime第2线仍受限。挑战、403/404、脚本/媒体发现分别记账；历史30/40不是今日可用率。本维护未访问站点、升级或推广规则。
- 取消可及时释放UI等待，但无法强制结束同时拒绝interrupt/cancel/close的外部提供者；读取/清理各最多2线程，饱和拒绝继续累积，容量需等待提供者返回或重启进程恢复。
- 无自动回归workflow；适合近期无人值守小包，不能取代观看任务。release仍绑定debug signingConfig，长期签名保管、升级身份及对应源码/传递许可要收口；本轮隔离证书APK不覆盖现有安装。
- 原路线仍缺真实HTTPS同步/更多冲突选择、历史/Bangumi同步，下载过期地址/重启/空间不足/完整性/删除闭环及部分资料/规则诊断。MX外播实际画面与进度未证明；画质/系统增强后置。
