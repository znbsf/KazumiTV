# KazumiTV 0.3.3 Preview 6

原生 Kotlin / Compose for TV / Media3 测试版，versionCode 52。基于 Preview5 之后的当前原生主线；完整迁移仍在进行。

## 本次改动

- 补齐旧 WebView 在第三方播放器脚本不兼容时的两类媒体发现：受限的页面已计算配置，以及当前页面中的字面量变量引用。保留正常发现优先级、媒体探测和请求上下文；页面跳转后，包括探测中的旧结果都会失效。
- AGE 第12集五条线路在旧电视 WebView66 与现代端 WebView143 的同功能候选上完成首帧、推进、拖动、暂停/继续短测。固定上游17条规则没有为此改写。
- 设置新增“播放诊断”：只保存白名单播放阶段、数字错误码及版本信息，最多200条/64 KiB；支持查看、JSON导出、本机最多三份和清空，不记录片名、网址、请求头、Cookie、网页或异常原文，不上传。

## 配置与升级

公开 APK 不内置弹弹play AppId / AppSecret。已有用户凭证保留，未配置时仍可播放视频。请使用覆盖安装保留现有收藏、历史和设置，不需要卸载或清除数据。

## 验证与剩余项

本次实现通过217项单元测试及release lint。两种WebView完成受控变量配置发现、导航期间旧探测失效和原有网页发现回归；两端播放诊断界面完成受控会话失败、本机JSON保存/容量、取消或无文件保存器、清空及用户数据保留专项。这些受控结果不代表全部真实网站已经验收。

akianime第2线、ezdmw第3线、白猫第6线仍有失败，详情见[逐源验证表](SOURCE-VALIDATION-20260922.md)。其他来源真实人工验证、真实网络恢复差异、搜索系统恢复和适用TV能力仍有未完成项。播放诊断当前不包含搜索、下载等全应用日志；文件保存器实际成功写入仍待适用设备验证。

不做整集播放测试，不以部分短测或受控测试宣布完整迁移。最终公开包哈希、设备验证和远端发布回读记录在配套发布核验文档。
