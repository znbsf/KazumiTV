# KazumiTV 0.3.3 Preview 5

原生 Kotlin / Compose for TV / Media3 测试版，versionCode 51。基于 Preview 4 之后的当前原生主线修复；完整迁移尚未完成。

## 改动

- 历史续播缺失集表时可单独重试目录；遇到目录验证码，显式打开“验证并恢复集表”，完成后保留当前播放器和进度并恢复选集能力。
- 验证返回尊重原暂停意图、实际后台停止和睡眠到期；修复一次返回关闭菜单后又误退暂停播放器的问题。
- 未明确配置 Referer 的规则在媒体探测收到 HTTP 400 时，最多去除自动补充的 Referer/Origin 重试一次，仍验证媒体响应。修复 aafun、moonci 部分线路的请求头兼容问题。
- 媒体及下载持续响应不再受文本请求的 30 秒总期限限制，连接与读取超时保留。
- 同域 HTTP 集表 GET 发生传输失败时，在严格条件下最多回退 HTTPS 一次；不改固定规则、不处理跨域/API/POST，也不把验证码或 HTTP 状态当作回退条件。

## 弹幕配置

公开 APK 不内置弹弹play AppId / AppSecret。用户可在“设置 → 弹幕服务与凭证”填写自己的配置；设备已有用户凭证保留。未配置时仍可播放视频。
