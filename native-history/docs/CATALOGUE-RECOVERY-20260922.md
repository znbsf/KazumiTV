# 集表失败后的单独重试

从历史继续播放时，首次目录请求失败后，媒体“重新解析”可以恢复单集，但原目录恢复effect不随媒体重试触发，选集、上下集及线路能力可能一直缺失。

播放器现增加“重试集表”：独立请求目录，不重新解析媒体或替换播放器；加载时禁止重复请求，失败保留再次重试入口。成功后恢复适用的选集、上一/下一集、线路入口，焦点回到已挂载的播放按钮。切源、换集及退出会取消旧请求，旧请求迟到的结果不能写回，也不能清除新请求加载状态。

验证构建为本地code50候选，SHA256 `91b5a41b48fffb5128061e7c59f6094eb2c475423b4847cd42a5feffc73dbdbc`，晚于公开Preview4，**未覆盖公开APK**。

- release/test构建、190项单测与lint通过。
- 旧电视WebView66与现代TV模拟器均通过 `catalogue-recovery`。首次媒体解析失败后明确重试，目录连续两次受控失败后可继续重试；加载中没有重复请求，失败没有自动循环。
- 真实本地视频渲染后暂停；目录恢复前后为同一个ExoPlayer实例，暂停位置变化小于500ms，媒体解析次数不增加。选集、上一/下一集和线路按钮恢复，焦点回播放按钮。
- 退出取消悬挂目录请求；模拟不配合取消的提供者延迟返回，结果未污染重新进入的新会话。
- 测试使用隔离偏好存储、隐身模式及本地媒体，没有声明真实网络中断通过。现代模拟器实际承载为Ethernet，关闭Wi-Fi不能证明断网；真实来源网络故障后的重解析和恢复仍需单独验收。
