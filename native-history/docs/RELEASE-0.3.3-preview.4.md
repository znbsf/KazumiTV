# KazumiTV 0.3.3 Preview 4

原生 Kotlin / Compose for TV / Media3 测试版，versionCode 50。包含 Preview 2 之后的播放、验证和历史导航修复；不是完整迁移或稳定版。

## 改动

- MXdm 搜索遇到 HTTP 200 限频提示页时，按站点间隔有限重试；避免把限频提示误报为空结果。
- 最近观看可直达番剧详情，保留原在线来源选集入口；历史详情返回后恢复详情按钮焦点，避免确认键意外续播。
- 修复播放器初始焦点偶发崩溃，改进旧 WebView 的嵌入页面媒体发现与验证恢复。
- 人工验证等待不再受原60秒总截止影响，退后台暂停检测、回前台继续；标准 MacCMS 旧模板控件在严格条件下兼容规则控件缺失，复用网站已有输入与提交处理。

## 弹幕配置

**本 APK 不内置弹弹play应用凭证。** 如需弹幕，请自行提供有效 AppId 和 AppSecret，在“设置 → 弹幕服务与凭证”保存后重新进入播放。应用不提供凭证申请功能；未配置时仍可使用视频播放。已保存在设备上的用户凭证继续优先使用。

## 验证范围与限制

- 190项单元测试及 release lint通过。最终APK在旧电视WebView66及现代TV模拟器通过无凭证设置保存/移除、密钥不回显、视频渲染推进及配置指引专项；旧电视MXdm第12集两条线路的首帧、推进、拖动及暂停/继续通过。
- 最近的固定17源全目录抽测为 code49：9源17线路短测通过，其余分别记录人工验证、网络、规则或解析问题。**未把该结果标为本APK重新完成17源验收**。
- code49同功能候选已验证 giriGiriLove 人工提交后恢复4条原搜索结果、真实跨源返回后再入播保进度，以及本机待机强停后手动重开从历史续播；按各自构建保留证据。
- 不做整集测试；短播放、受控验证码和单设备结果不代表全部来源、完整观看或完整迁移完成。dalvdm等真实挑战仍待人工完成；xfdmneo独立候选规则尚未推广。
- API24及以上；主要实机为Android 9小米电视，另有现代TV模拟器检查。保持现有开发签名，不同签名不能覆盖升级，升级前备份收藏与历史。
