# 0.3.1：播放解析与验证迁移

本轮针对公开测试版反馈继续修复。修复在 `0.3.1-dev` / versionCode 44 完成真机验证，发布为 `0.3.1-preview.1` / versionCode 45；保留 `0.3.0-preview.1` 的已发布 APK 或标签。以下是小米 Android 9 / ARMv7 / WebView 66 的证据，不代表所有站点和设备均通过。

## 原因与修复

1. **网页运行失败不等于播放器解码失败。** 原版 Flutter 以 WebView 获取地址，再交给 media-kit/libmpv；原生版以 WebView/来源接口获取地址，再交给 Media3。本次两个主要故障发生在取得地址之前。
2. **MacCMS 播放数据遗漏。** `moonci` 的页面已经含有 `player_*` 对象。新增只解析数据的兼容路径，支持明文、百分号编码和 Base64 编码；不在本机执行来源 JavaScript。取得地址后仍检查真实 HTTP 响应与媒体格式。第一条线路的 HTTP 400 保留为媒体错误，不再被无关脚本错误覆盖。
3. **Sorani 的现代网页代码不兼容旧引擎。** 首轮修复还发现大网页偶发加载超时，因此现在优先依据匹配的 API 规则和播放页路径，直接查询剧集、线路和播放接口，检查返回作品 ID 与集序号；减少依赖整页运行。页面元数据保留为兼容路径。仅匹配明确的 Sorani 站点/接口；检查服务器的 `canPlay`、试看及前置步骤，不绕过账号或付费要求。其网页或接口变化仍可能需要后续适配。
4. **验证此前只有网页入口。** 迁移原版 `CaptchaVerificationService` 的三类流程：图片提取及人工输入后自动填写提交；按规则自动点击按钮；执行规则提供的脚本，兼容 `KazumiCaptcha.done/fail` 和异步返回。使用 ES5 语法，网页没有访问原生对象的 JavaScript bridge。
5. **验证与原请求连续性。** 自动验证串行执行，避免低内存电视同时创建多个 WebView；有超时与取消，成功后只重试一次原请求。保留 GET/表单 POST 及请求体、共享 Cookie、结束和取消时落盘。HTTP 403/429 的响应先检查是否为已配置的挑战页面，不直接丢掉验证上下文。
6. **验证成功判定。** 已见到挑战或执行过操作，并连续取得稳定的正常页面，才返回调用方；空页面、按钮无效、规则失败、挑战仍存在不能报成功。原请求重试仍会再次检查挑战。图片更新后清空旧答案并提示重新输入。通用图片 OCR 不在本次实现中。
7. **电视操作。** 验证页提供可选择的原生输入框、重新检测/加载和网页光标；方向键移动、确定点击、长按确定进入拖动、再次确定松开、返回退出光标。复杂跨域挑战及所有拖动站点仍需分别验证。

## 验证边界

- `VerificationRegression` 在同一电视的 WebView 66 检查按钮、异步脚本、图片输入/提交、失败与空白页不能误判、取消，以及 Cookie 和原 POST 请求恢复。自动按钮和脚本使用受控站点，不声称所有真实站点均通过。
- `RealSourceRegression` 使用真实网络来源，报告每条线路的成功或失败；测试流程结束本身不代表全部线路成功。
- `RealPlaybackUiRegression` 最终通过来源页、选第 12 集、进入生产播放器、返回原选集位置及从约 12 秒续播。测试来源使用独立名称，历史在结束后恢复快照并核对相等。早期测试因 Dialog 中的 Context 与隔离存储不一致误报，随后修正测试数据边界；源页面现在将同一份来源目录传给播放会话。
- 142 项单元测试通过；Release lint 为 0 error（现有警告保留）。验证回归另在真机通过遥控光标移动/点击/返回及 HTTP 403 挑战后恢复原 POST 请求。
- 最后补跑既有解析回归：延迟 DOM、无后缀 XHR/HLS、伪媒体拒绝、验证页识别、HTTP 503 错误及取消均通过；换源保进度、失败重试、取消保持暂停和歧义集数回归通过。实际 Release 构建仍能使用内置弹幕凭证完成映射及取得 7309 条弹幕。
- 单元测试覆盖编码、无效 URL、嵌套数据、验证状态转移、Sorani 当前集选择及服务器拒绝/试看边界。
- 完整长时播放、网络切换、待机、更多来源的挑战、老引擎无法执行的其他网页及复杂拖动验证仍不在已通过范围内。

原始页面、签名媒体地址和设备截图只保存在本机忽略目录 `artifacts/`，不写入发布文档或提交仓库。

本机证据入口：`real-play-device-final.txt`（三家实际播放）、`verification-live2.txt`（真实图片验证）、`real-play-ui4.txt`（完整选集返回续播）、`verification-device-final3.txt`（自动验证和光标）、`resolver-regression-final.txt`、`source-transfer-final.txt`、`danmaku-final.txt`。上述文件均位于 `artifacts/`。
