## 已有能力与仍待验收

PlayerScreen:156 已有结束自动下一集与睡眠计时约束；168已有历史续播且最后5秒不续；SourceScreen:97/108/191已有返回当前集与焦点恢复。不能再标成“完全没做”。但 PlaybackSessionScreen 大量 remember 状态未持久化；进程重建恢复、结束连播与定时冲突、换源后返回外层页面上下文仍需独立真机测试。

## 本轮紧边界实现

只修改 `PlayerScreen.kt` 与 `PlayerControls.kt`：动作分组、可达错误重试、隐藏快进反馈、确认键语义。保留现有页面结构、字号体系、绿色、返回层级；不动规则、解析器、播放器内核、构建或真机。

参考当前 14sp 操作/13sp辅助文本、38dp焦点目标，而不是全局放大缩小；分组后主要操作应在普通电视宽度一屏内。运行状态与错误状态分别截图验收，面板打开/返回、键盘长按必须实际回归。

## 本轮实现交接

已落实（尚待统一编译与真机回归）：常用动作分组，其他功能进入“设置”；失败时“重新加载”优先显示并获得焦点；隐藏控制时快进/退显示短时进度；确认键直接暂停并显示控制；PlayerAction 焦点外形改为小圆角而不是胶囊。onChooseRoad 同时传递暂停前播放意图，由会话层处理恢复。

新增 `PlayerControlsRegression`，用受控有效/无效媒体检查分组、菜单返回、快进反馈、单次确认暂停与错误重试并保存4张截图。使用隔离设置和隐身模式，结束后断言真实设置/历史未变化。ExternalPlaybackRegression 与 DisplayModeRegression 已更新为通过“设置”进入低频功能。

复核现代模拟器截图发现首张仅缓冲、有时长无首帧，设置面板与常规控件同时显示造成遮挡。测试已改为播放进度推进、暂停并检查已渲染首帧后截图，提供全部7项常用控件并逐项检查屏内可见及遥控焦点到达设置。打开菜单时隐藏普通标题和控制栏；播放错误会退出菜单并显示恢复入口。修改尚待父代理重新构建与运行。
