# 2026-09-23 播放诊断子集

设置新增“播放诊断”：查看当前进程的解析阶段/结果和播放器数字错误码、导出 JSON、保存本机报告、清空。它覆盖 B15 的播放诊断部分，不代表搜索、下载、完整验证等全应用日志已经迁移。

## 数据边界

- 内存最多 200 条，完整报告最多 64 KiB，超限丢弃最旧事件并计数。
- 容器只接收枚举和有界整数。resolver 原始消息先经完整白名单语法匹配，未知消息直接丢弃；不保存原消息。
- 不写入片名、节目/媒体网址、请求头、Cookie、账号、网页或异常原文。报告头仅包含受限版本格式、Android SDK 和固定字段。
- 不上传网络。仅用户点击后写文件；应用重启后内存日志清空。本机报告保留最近三份；清空删除内存和本机报告，不删除用户已导出到别处的文件。
- 没有文件保存器的电视可保存应用内本机报告。目前本机报告没有直接分享/打开旧报告的入口；文件保存器实际成功写入的端到端分支仍待具备该组件的设备验证。
