# ADR-001：以既有Flutter TV业务为主线的有界试验

## 目标与基线

独立分支：`codex/flutter-tv-reuse-lab-20261001`。独立对象库及工作树位于当前任务的`kazumi-flutter-tv-lab-20261001`；旧Flutter TV、原生main及用户脏目录保持原状。既有远端仍是`znbsf/KazumiTV`，没有新建远端。

冻结上游观察值：`Predidit/Kazumi@0ea0bbd455a4ce4d30927f84cd50d1d2b2308a18`，2026-10-01。本轮是“底座＋选定提交”，不是合并所有最新上游，也不保证包含该观察值之后的提交。

首轮复用Flutter 3.47.3 / Dart 3.13.3及锁文件，工具与Pub缓存隔离到本任务。保留media-kit固定`994465d9bfca3f39d0b41199d16e7fd93fe97881`和既有libmpv版本，不升级媒体栈、替换解析器、存储或下载引擎。测试并发2、Gradle worker最多2，同一时间只跑一个构建。

## 首轮范围

1. 在干净底座重跑自动回归，确认构建环境；历史证据只作参考。
2. 选择低依赖修复：搜索历史去重顺序、启动尊重WebDAV历史同步开关、XPath非2xx验证码响应回退。逐项保存完整SHA、patch及适用性检查。依赖/菜单/播放器布局升级不捆绑采纳。
3. 实现一个TV搜索UX切片：从某作品进入详情后，结果重排仍按作品id恢复返回焦点及下一次OK目标；目标消失、空列表、新查询必须有明确回退，不迁移一套新搜索业务。
4. 评估Compose的局部边界；没有具体收益时，记录暂缓就是有效结论，不为“混合”而增加层数。

## Compose候选与进入条件

优先考虑独立Activity或职责纯粹的系统组件；不默认在Flutter页面里同屏嵌套另一套TV焦点树和Surface。Flutter已经具备焦点系统及原生libmpv桥，不能以“原生更好”作为引入条件。

候选须先说明：一个可复现Flutter缺陷、现有桥为何不足、Compose的具体改善、接入与测试成本。若涉及播放UI，先证明保留libmpv可行，不顺带更换Media3或全部业务。

最小协议约束：Dart发起请求并持有`requestId`、页面/查询generation和取消状态；只传所需身份/意图，敏感URL、headers、Cookie不得写入诊断。原生只返回`completed/cancelled/failed`与限定结果。重复或过期结果忽略；Back关闭原生页并返回Flutter的原锚点，HOME暂停/释放资源，Activity重建不能重放业务写入。无存活Dart请求时取消或由Dart明确恢复，不让原生自行创建第二份业务状态。

首轮若Flutter修复已解决具体UX且未发现足以抵偿跨框架成本的缺口，暂缓Compose原型；不能把“引入Compose”列为必须完成的产品功能。

首轮的只读候选是原生`EpisodeBrowser.kt`/`EpisodeWindow.kt`的长篇50项分段、倒序与序号定位。第三轮按已批准的架构目标接入独立 Compose Activity 做局部验证，运行时开关默认关闭，缺组件时回退到 Flutter 序号定位。Dart 只发送当前/已看等显示快照和不透明标识，并在接收时验证 session、revision、成员与单次动作；业务和播放器仍归现有 Dart/media-kit。组件的生命周期协议和 Kotlin 编译可自动验证，但相对等价 Flutter 控件的性能收益需要同设备对照，尚未证明全面采用的必要性。

将来纯展示组件只接收`sessionId/revision/items{opaqueId,label,current,seen}`快照，返回`sessionId/revision/commandId/action/opaqueId`。Dart核验版本、成员与重复命令后执行原有业务；纯选集组件不接收媒体URL、Cookie或凭据。若接入需要两套可写状态或第二个播放器，停止该候选。

## 验收及停止条件

自动检查包括已有完整Flutter测试、静态分析、普通版选集金图、TV构建边界、选定上游修复回归，以及新搜索路由返回的失败→修复证据。Android TV ARMv7 release须可构建并记录SHA、manifest及签名身份；这不等于设备播放验收。

新包真实来源、目标电视、声音、实体遥控、待机/进程恢复本轮没有操作条件时记为未验证。后续只选两条代表来源，用同一电视完成搜索→详情→来源→画面/进度→暂停快进→换集/线路→返回→历史续播，不恢复用户已取消的整集测试，也不要求17源全绿。

遇依赖缺失先使用现有缓存或任务内普通工具安装；登录、UAC、管理员安装、设备占用、同文件其他owner修改时停止相关步骤并继续独立工作。若上游patch引入媒体/依赖级联或普通版回归，撤回该候选而不是扩大升级范围。若基线不能构建，先记录环境/基线阻断，禁止继续堆Compose层。
