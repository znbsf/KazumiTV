# Issue #9：显式重新选源

基线：`a2735b17b4ac6354d9ed1afbe10a6fce344e581c`（main）。修复分支：`fix/issue-9-source-switch`。此变更供后续版本审查，不修改 v0.4.2 发布产物。

## 行为

- TV 详情页保留“开始观看”的历史续播，并新增“重新选源”，直接打开共享 SourceSheet；无历史时仍按原流程选源。
- 在线播放器 TV 设置菜单、普通/紧凑菜单和播放失败页均提供“更换播放源”，与原来的同插件“选集 / 换线路”分开；离线播放不显示跨插件入口。
- 播放器选源使用当前集数与进度快照，不读取其他来源较旧的历史来替代当前状态。确认同作品/季度后，只有唯一的普通集数语义匹配才提供续播；不明确时必须手动选集并从零播放。
- 新源在独立解析器中预解析。选源或解析取消不切换播放器，不写入新源历史；取消、关闭页面和过期结果均有失效检查。
- 解析成功后复用当前播放器路由，不叠加第二个 `/video/`。底层初始化失败时恢复原播放上下文，并在原来有有效媒体时尝试从原位置重新打开；恢复本身失败仍保留原源重试入口。未初始化成功的候选不能写历史。
- 选源关闭后恢复原可用焦点，TV 设置菜单恢复到设置按钮；所有新增控件使用现有 Material/TV 按钮与主题。
