# KazumiTV 0.4.6 发布候选

状态：发布准备，尚未公开 Release。范围为原 main `b5e2fe9ca89131836729e8500b68bcd5526ba711` 的稳定修复，加上已验收的首页焦点响应优化 `ed17266a`。

首页优化的 70 项针对性测试及真机导航行为通过；用户试用正式签名体验包 0.4.6-focus.20261030 / 206661 后确认“跟手多了”，要求合并并继续准备 release。此次三 ABI 正式附件使用基础号 20667 重建；旧 a12782ea / 20665 附件仅留作历史，不用于本次发布。详见 [当前状态](PROJECT-STATUS.md)。

## 本版变化

- **手机输入更完整**：来源检索、弹幕检索/输入、剧集数字定位和验证码支持显式手机输入。Bangumi Token、WebDAV 密码只接收新内容，不向手机回读已有凭据。手机确认文本后，搜索、发送、保存等业务动作仍由电视确认。
- **下载更可靠**：修复恢复下载和分段完整性检查；多个任务的进度能一起刷新，长剧集列表按需创建行。
- **播放与界面少做重复工作**：合并连续快进退；开关选集栏、缓冲变化不再带动整个播放器重建；收窄首页、历史与选集下载状态更新，隐藏控制栏停止无效进度刷新。
- **首页遥控更跟手**：焦点边框立即亮起，缩放为 90 ms、跨行滚动为 100 ms；长按重复键直接定位，分类栏滚动同步加快。
- **历史与日志开销降低**：合并进度保存、增量更新历史列表，媒体会话按状态和进度变化发布；日志限制单条及总容量，只在需要时格式化和订阅。
- **来源与网络处理改善**：规则更新失败可保留、停用或移除；停用来源不会继续处理旧搜索。Bangumi 搜索、评论及元数据请求增加有界备用接口切换；弹幕限流提示及取消后的迟到请求处理修复。
- **Android 9 更新兼容**：修复读取下载 APK 签名的兼容问题。

## 已有验证与限制

原程序基线的 GitHub Actions `41034253394` 已通过检查及三 ABI QA 构建。各修复已有组件、受控网络和专项测试；新增首页焦点优化另有 70 项针对性测试、ARMv7 真机导航及用户手感确认。发布阶段仅调整版本与文档，复用适用结论，不因合并重跑验证；正式签名附件独立构建，不把 QA 包当作正式附件。

同程序 main 正式签名包在小米 Android 9 / ARMv7 上完成保数据覆盖升级，验证了播放、暂停/继续、切集、连续快进退、选集开关、历史联动、下载暂停及重启续传、规则启停、搜索和日志界面。最新 main 包的搜索与 WebDAV 密码已用真实手机验证；来源检索、Bangumi Token、弹幕输入的真实手机证据来自合并前同功能隔离 QA。用户随后自行试用了输入入口，反馈基本测试完成，不将其扩大为所有字段逐项验收。

尚未全面验收全部来源、全部输入框真机组合、长列表与并行下载压力、长时间播放、声画同步或帧耗时；ARM64/x86_64 不宣称实体设备验收。应用内完整下载并安装本次正式更新尚待可用的正式更新候选，不能用 ADB 覆盖升级代替。

第三方接口及视频源可用性仍受网络影响，本轮不开代理时评论主/备用接口均曾超时。蓝牙音箱曾有发送队列积压，重连后短时观察未再出现；未据此修改播放器或声明永久解决。未合入的 Gecko 解析实验、硬解恢复实验及个人电视 preview 均不包含在本版。

## 版本与升级

版本 `0.4.6`，基础构建号 **20667**；ARMv7 / ARM64 / x86_64 对应 **206671 / 206672 / 206674**，高于电视当前焦点体验包 206661。

沿用包名 `com.znbsf.kazumi.fluttertv` 与长期正式签名，可覆盖同签名的旧正式版及预览版，不需要卸载。计划附件为三个正式 APK、逐 ABI 验证 JSON、SHA256SUMS、对应源码及原生依赖构建资料/许可证。实际产物身份以构建后验证 JSON 为准；构建、设备安装和公开发布分别记录。
