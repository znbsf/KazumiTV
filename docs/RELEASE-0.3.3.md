# KazumiTV 0.3.3 Preview 1

本轮播放优先修复测试版，versionCode 47。保持原生 Kotlin / Compose / Media3 主线和现有首页。

- 补顶层 Artplayer 明确静态媒体地址的通用发现，修复旧 WebView 无法运行网站播放器脚本时的一个遗漏；不执行抓取脚本，不猜测动态地址，继续进行媒体探测。
- 修复 Android 9 真正杀进程后，保存的节目/续播对象通过 Serializable 反序列化导致的启动崩溃；关联作品与人物导航采用相同基础类型保存策略。
- 搜索保存浏览焦点、可见节目锚点及偏移，重建最多五页原窗口；恢复加载失败可以继续重试，空结果不会永久卡住恢复标志。
- 换线手选页面跟随目录重置索引，避免恢复期间目录尚为空或重排时越界。

用户本轮要求取消整集播放测试，采用针对性短时验证。不会将首帧、短播、组件恢复或单个设备结果表述为全部迁移完成。验证明细见[本轮执行记录](PLAYBACK-EXECUTION-20260922.md)，其余缺口见[迁移台账](MIGRATION-STATUS.md)。

验证：188项单测、release构建与lint通过；小米Android 9最终包MXdm第12集两线短测、搜索/换线/会话恢复、四类导航Parcel序列化通过。真实baimao第13集在HOME后系统杀进程，原任务以新PID恢复同集约01:06并保持暂停，显式继续至01:17且弹幕可见。设置、历史、搜索历史已恢复并核对相等。完整17源较早候选轮为7源14线短测通过，构建边界和失败项见执行记录。
