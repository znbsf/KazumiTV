# KazumiTV 0.3.2 Preview 1 发布候选记录

状态：代码及本地APK已准备；用户要求先推送代码并暂停，尚未创建该版本的公开Release。

这是播放优先迁移的公开测试版，不是全功能稳定版。原生包名与已有0.3.x一致，保留开发签名，用户历史和收藏不重置。Legacy归档版保留原发布。

## 本次修复

- 对照固定KazumiRules正式目录17条，补齐电视缺少来源并逐线路抽测；修复XPath上下文、兄弟轴和union等通用解析遗漏。
- 统一规则UA/Referer和实际媒体请求上下文。根据实际WebView能力选择提前注入或兼容发现；旧内核增加响应式网页尺寸、受限跨域播放器iframe回退、早期XHR历史记录补偿和无后缀Range候选。
- 发现候选仍须媒体探测；普通接口与明确媒体分开预算，失败iframe不阻断后续候选，超时和取消仍有边界。
- 验证保留原POST/Cookie上下文，恢复空检测配置的上游回退；限频页面单独识别并有界重试，失败/取消/渲染退出清理。
- 过期播放地址重新解析并保留位置和暂停意图；保存最小会话目录引用，重建重新载入。换源/换集后返回当前来源与当前集。
- 播放器常用操作与设置分组，轻量绿色焦点，修复原生视频视图抢焦点与物理返回。系统上一/下一集及后台恢复补齐。
- 自动弹幕匹配增加作品与季度歧义检查；包内凭证继续内置，仍可能从APK提取。补齐离线许可、署名与对应源码入口。

## 验证与范围

183项单元测试通过，Release及测试APK构建、lint通过。真实Android9小米电视（WebView66）和独立API36模拟器（WebView143）分别验证，模拟器不代表电视解码与性能。

- 两环境：网页发现的早期XHR、跨域、无Range、百分比布局、小广告排除、失败iframe继续、候选预算；组件重建、过期HTTP403恢复、换源后返回、系统MediaController及HOME前后台恢复。
- 电视：真实Sorani第12集选集后进入播放器、返回选集及续播；内置弹幕真实服务7310条自动挂载并实际显示（自制视频验证叠加层）；离线许可正文遥控阅读。
- 真实验证：LMM两环境自动按钮验证；mutefun两环境、mgnacg现代环境图片人工输入后恢复搜索。不是OCR自动识别。
- 早期0.3.2开发包已有Sorani第01集从零实时播放23分42秒、自然结束切第02集继续10秒记录，设置和历史恢复原状。其APK哈希与最终包区分；不声称最终包所有来源都整集验收。

完整17源结果、后续补测和失败阶段见[逐源矩阵](SOURCE-VALIDATION-20260920.md)。构建与实测记录见[执行记录](PLAYBACK-EXECUTION-20260920.md)，未完成项见[迁移台账](MIGRATION-STATUS.md)。

## 仍需完成

部分来源/线路仍失败，网络波动、站点变化、旧浏览器脚本及人工验证没有全部解决。实际待机、网络切换、操作系统杀进程恢复、跨站整集弹幕同步与热稳定未全面验证。超分、自动刷新率、HDR/直通优化、账号/多设备同步及部分下载增强继续列为缺口，未从迁移表删除。

安装后在电视启动器打开“KazumiTV 原生”；“KazumiTV Legacy”是另一条归档路线。请以Release对应源码标签和APK SHA256核对版本。
