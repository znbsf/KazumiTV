# 迁移实现与验证台账

更新：2026-09-16。目标：迁移表中适用于TV的功能基本全部落地并测试。S5–S7后置能力仍在范围内，不因后置视为完成。明确非TV或设备不支持项须保留判断依据。

状态分为未实施、部分实现、已实现待验证、已验证、不适用待说明。当前只记录可核对进展，不以构建通过代表完整用户路径通过。

本轮起不使用sub2api；旧独立报告只作为参考资料。

**后续最高优先级：播放可靠性。** 播放是关键功能，先补上游通用能力与真实观看闭环，再推进外围增强；不以部分来源首帧代替完整验收。执行原则见[后续计划](ROADMAP.md#首要原则播放是关键功能)。
