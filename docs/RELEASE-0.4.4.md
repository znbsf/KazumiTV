# KazumiTV 0.4.4 发布说明草稿

计划中的下一版，尚未发布；当前正式版仍为 0.4.3。本文描述本轮候选范围，最终版本、产物和验收状态以 [项目状态](PROJECT-STATUS.md) 为准。

## 使用变化

- 首页增加手机遥控入口。手机和电视连接同一局域网后扫码，可使用方向、确认、返回、首页数字、播放/暂停、快进退、上下集与选集，以及受限的普通文本输入。
- 手机页面随应用使用浅色或深色风格，并提供可关闭的按键震动；手机浏览器不支持震动时，遥控仍可使用。
- 可选择记住配对 7 天。电视重新打开应用后恢复连接，原网址可收藏使用；到期或主动取消配对后重新扫码。电视 IP 改变可能需要重新扫码。临时连接仍按 10 分钟闲置期限关闭。
- 电视显示等待连接、在线遥控端数量和暂停状态。断开全部会暂停连接并保留配对，需主动恢复；取消配对会撤销旧链接。在线数量按浏览器身份统计，不保证等于物理手机数量。
- **首页数字键**输入编号后稍候，已看番剧直接尝试续播上次集数和进度；无记录则进入详情。**确认键始终查看详情**，包括数字输入后主动按确认。普通海报点击也保留详情入口。历史来源不可用时可回到详情重新选源。
- 播放器选集面板连续 3 秒无操作自动收起，继续操作重新计时；评论页不自动收起。
- 热门首页优先显示本地目录缓存，冷启动后台刷新，手动刷新失败保留旧内容和上次成功时间。6 小时以上标记较旧，30 天后不再使用；6 小时不是定时刷新周期。
- 搜索可用二维码向电视提交关键词。规则仓库修复已安装条目和安装后的遥控焦点，便于遍历长列表。
- 源健康探测和跨番剧复用明确标为实验功能。有本番观看记录优先续播；无记录时，在开启相关选项后，尝试一个已有成功记录且规则兼容的来源，重新搜索匹配当前作品，未命中或失败回到普通搜索/选源。
- 改善普通首次观看搜索、按钮焦点提示和部分 direct 播放输出初始化；保留有确认步骤的软件兼容恢复，不自动全源探测或无限重试。

- 普通模式自动保留解析请求终态、WebView资源错误码/域名/主框架标识，以及播放器错误详情和有限的原生日志上下文；对URL和凭据脱敏，重试后仍能回查。日志用于定位间歇失败，不宣称来源故障已修复。

## 配对与设备边界

手机遥控只在电视应用处于前台时可用；7 天表示配对有效期，不是后台保活承诺。普通文本原文读取需要在电视上单独授权，每次连接恢复后重新授权。配对凭据不随收藏/历史备份导出。

电源、系统桌面、系统音量继续使用实体遥控器。番剧快捷链接、从其他应用拉起、待机唤醒留在 [Issue #23](https://github.com/znbsf/KazumiTV/issues/23) 后续开发；个人电视频道/EPG preview 不在本版范围。

## 验证与安装

r3 的手机界面、播放控制、源健康标识/首次选源和此前失败视频已有用户验收。2026-10-18用户确认r7剩余电视项目通过，PR20与PR22已合并；对应main的检查与三ABI候选构建均成功。自然7天连接和全部手机震动支持不在短时验收范围。新增诊断补丁的验证与产物另记于项目状态，不沿用旧包证据。

播放来源仍可能失效、超时或需要验证；一次资源解析超时不等于已确定播放器缺陷或网站原因。不承诺所有来源、整集音画同步或 ARM64/x86_64 实机均通过。

正式版本计划沿用 `com.znbsf.kazumi.fluttertv` 与既有正式证书，使用递增版本覆盖升级。当前 `remoteqa` 测试包不能充当正式附件，也不自动迁移测试包数据。最终三 ABI APK、源码包、许可、验证回执与 SHA256SUMS 需完成正式构建后提供。

## 发布候选

计划版本0.4.4+20556，正式三ABI versionCode为205561/205562/205564。CI仍使用独立remoteqa测试身份，版本0.4.4-rc.1；正式签名候选单独构建与验证，不替换已发布0.4.3附件。README新增[候选功能截图](screenshots/v0.4.4/README.md)。

发布前核对：本轮补丁CI、正式签名/ABI/哈希/源码对应、测试包日志落盘；正式包保数据升级与公开Release须在用户决定发布时执行。已知7sefun解析阶段间歇失败和mgnacg未知原生错误仍保留，见播放恢复runbook；本版只补可追查证据，不以一次播放成功宣告根因消失。
