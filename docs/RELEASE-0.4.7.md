# KazumiTV 0.4.7 发布准备

当前是发布准备稿，正式附件和升级验证完成后再填写最终构建提交、哈希及验收结果。公开下载仍为 0.4.6。

## 本版变化

- 电视弹窗改用右侧面板，改善多层页面返回、焦点恢复、选源和选集布局；讨论阅读、收藏菜单、系统文件选择器缺失等问题已有修复。
- 番剧列表和资料请求更早使用备用路径，封面按显示尺寸请求并支持失败重试；这不代表所有线路的加载速度都已测量或得到保证。
- 弹幕独立缓存默认开启，上限 256 MiB，可选 64 MiB～1 GiB。弹幕、搜索和剧集列表缓存 6 小时，番剧 ID 匹配缓存 7 天；相同请求合并，遇到 429 后暂停请求，更新失败时可使用 30 天内的旧数据。
- 近期视频缓存作为独立实验功能，默认关闭、容量默认 2 GiB，支持已完整保存的视频离线重播及逐集清理。删除视频不会清除独立弹幕缓存。
- 电视错误日志可生成短期脱敏快照，由已配对手机预览、复制或下载，不自动上传。

## 使用入口

- 弹幕缓存：设置 → 弹幕设置 → 弹幕缓存；存储与日志中也有入口。
- 视频缓存：设置 → 近期视频缓存。
- 手机日志：设置 → 存储与日志 → 错误日志 → 手机导出；手机遥控页展开“问题反馈与日志”获取文件。快照 5 分钟有效，电视可提前停止导出。

## 验证范围

TV UI 复用 2026-11-08 已完成的既有验收，见本地 TV-UI-ACCEPTANCE-20261104 记录。新增功能使用程序提交 `aeeef815457b74f4e27f5760d35b896a1d468a72`、普通入口 QA `0.4.7-qa.1 / 207221`，在 MiTV-ASTP0 / Android 9 上验证；安装包回读 SHA256 与构建产物一致，QA 数据保留。

- HLS 和 MP4 各完整保存一集；关闭本机测试来源服务、重启 QA 后，均看到本地缓存视频画面。此处使用自行生成的测试视频，不宣称覆盖所有媒体格式、声画质量或性能。
- 重启后的两次离线播放仍显示弹幕，弹幕服务 HTTP 请求数为 0。删除视频后，独立弹幕缓存的 3 条数据仍在。
- 弹幕缓存开关及 128/256 MiB 设置实际持久化；最终恢复开启、256 MiB。视频缓存恢复关闭、2 GiB，测试视频、测试来源和新增观看记录已移除，原有数据保留。
- 电视生成日志快照后，桌面浏览器实际获取、预览并下载 UTF-8 文本，复制按钮报告成功；停止导出后网页预览清空、获取按钮禁用。未读取系统剪贴板核对内容，也未向 GitHub 上传日志。

用户本次暂时不能配合扫码，**真实手机浏览器的复制和下载未验**。正式签名三 ABI 包、正式包保留数据升级及公开附件核验也尚未执行。先保留在 TV UI 分支及合并草稿，待补齐手机验收或用户明确接受这项限制后，再按原授权合入 main 并继续正式交付。已有有效的自动化与界面验收继续复用，不因合并重复全量测试。

视频缓存不会补齐跳过或未完成的片段；直播、多轨/多清晰度、DRM 及不支持的媒体格式沿用原播放路径。弹幕缓存能减少调用，不保证消除服务端额度限制；提高配额申请与客户端发布分别跟踪。脱敏日志提交前仍需检查内容。

## 正式交付

计划使用 0.4.7 / 基础构建号 20723，ARMv7、ARM64、x86_64 分包分别为 207231、207232、207234；若新增程序修复需要改变构建身份，以最终产物回执为准。沿用正式包名和长期证书，保留现有收藏、历史与设置。发布附件应包含三个正式 APK、逐 ABI 验证 JSON、SHA256SUMS、对应源码、许可证及原生依赖说明。
