# KazumiTV 0.4.7 发布准备

候选已合入 main，正式签名附件和 ARMv7 覆盖升级检查已完成，GitHub Release 草稿的 11 个附件已核对名称、大小和远端 SHA256 digest 一致。尚未公开发布，当前公开下载仍为 0.4.6。

## 本版变化

- 电视弹窗改用右侧面板，改善多层页面返回、焦点恢复、选源和选集布局；讨论阅读、收藏菜单、系统文件选择器缺失等问题已有修复。
- 番剧列表和资料请求更早使用备用路径，封面按显示尺寸请求并支持失败重试；这不代表所有线路的加载速度都已测量或得到保证。
- 弹幕独立缓存默认开启，上限 256 MiB，可选 64 MiB～1 GiB。弹幕、搜索和剧集列表缓存 6 小时，番剧 ID 匹配缓存 7 天；相同请求合并，遇到 429 后暂停请求，更新失败时可使用 30 天内的旧数据。
- 近期视频缓存作为独立实验功能，默认关闭、容量默认 2 GiB，支持已完整保存的视频离线重播及逐集清理。删除视频不会清除独立弹幕缓存。
- 电视错误日志可生成短期脱敏快照，由已配对手机预览、复制或下载，不自动上传。

## 使用入口

- 弹幕缓存：设置 → 弹幕设置 → 弹幕缓存；存储与日志中也有入口。
- 视频缓存：设置 → 近期视频缓存。
- 手机日志：设置 → 存储与日志 → 错误日志 → 手机导出；手机遥控页展开“问题反馈与日志”获取文件。快照 5 分钟有效，电视可提前停止导出。
