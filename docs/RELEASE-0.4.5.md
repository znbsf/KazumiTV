# KazumiTV 0.4.5 发布说明

已于2026-10-24正式发布为 [Latest](https://github.com/znbsf/KazumiTV/releases/tag/v0.4.5)，非草稿/预发布；11项公开附件已逐项匿名实际下载，大小和SHA256全部核对。

本版集中修复播放解析与换源时的请求上下文，沿用现有播放器内核和长期正式签名。

- 普通解析失败后，仅跟随来源明确提供的唯一后续 HTML 播放页一层；额外解析最多 10 秒并计入总预算，不无限递归。后续失败时可一次复用近期首帧已确认的同集地址缓存，保留原请求头。
- HHJX 补救改按具体故障条件判断：固定剧集、唯一当前 iframe、对应子框架 POST 403 与 `Origin:null` 等条件必须同时成立；正常解析优先，信息不完整、认证请求或歧义时不启用。Android/WebView 版本号本身不触发补救。
- 换源预解析冻结 UA/Referer，提交沿用同一快照；失败回滚恢复旧播放请求上下文。
- 原生日志遇到非法百分号编码时不再导致日志处理异常，继续保留脱敏。
- README 中电视首页与界面展示在前，手机遥控介绍在后。

### 验证范围

- PR28 与版本 PR30 的检查及 ARMv7/ARM64/x86_64 构建全部通过；相关完整 Flutter 回归 1167 项通过。
- MiTV Android 9 / ARMv7 / WebView 66 的同源码 QA 包已观察到 7sefun、DM84 第01集实际画面、正进度、暂停继续和历史接续。
- 本次长期正式签名 x86_64 包在独立 GoogleTV API36 / WebView143 模拟器上，从正式 0.4.3 保数据覆盖升级至 0.4.5：UID、首次安装时间、数据目录及可见播放设置保持；7sefun 第01集有实际动画和弹幕。个人电视的正式版未覆盖。
- 三正式 APK 均校验证书、版本/ABI、TV 入口、非 debug、probe/内部 QA 标记缺席、ZIP 对齐及原 libmpv 哈希；签名前后非签名 payload 相同。

尚未验收：音频/声画同步、长稳、全部来源、真实新版 WebView 的 HHJX 特定 403 复现，以及保持旧播放器的换源失败回滚。来源站点失效、验证码/挑战和部分 Bangumi 请求超时仍可能存在。

QA/Gecko 实验留在独立草稿 PR29，规则 overlay 暂缓，均未合入本版。正式候选使用原合法弹幕构建配置；无配置 CI 包的弹幕 403 不作为本版视频失败。

### 下载与升级

按设备 CPU 选择 `armeabi-v7a`、`arm64-v8a` 或 `x86_64`。正式应用包名不变：`com.znbsf.kazumi.fluttertv`，沿用原长期证书，可正常覆盖同签名旧正式版；不要卸载来升级，建议先使用应用内备份。

基础构建号 **20562**，三 ABI 版本码 **205621 / 205622 / 205624**。精确构建源码与 tag：`57ba3a356e32721abccac0b16bb920eb5cb2f438`，已通过 PR30 合入 main（merge `3fc9f8c4399de1290f494a9a7b74a1e5c5176a99`，完整源码树相同）。

附件含三个正式 APK、三个构建时验证 JSON、SHA256SUMS、对应 Android TV 源码、原生依赖构建资料与许可/NOTICE。验证 JSON 的 installed/published 字段为构建时快照，不代表本条发布后的状态。源码与许可不含私有签名材料或构建配置。
