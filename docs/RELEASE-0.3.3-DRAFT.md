# KazumiTV v0.3.3

电视播放与首页更新。

## 更新内容

- 改进真实播放来源的切换、选集、进度续播，以及从历史和首页最近观看返回播放的遥控路径。
- 更新电视首页：单行导航、六列节目卡片、最近观看入口，并改善详情返回后的焦点与位置恢复。
- 改进播放器控制和异常恢复路径。

## 安装与已知范围

- 可在已发布的 `v0.3.3-preview.6` 上直接覆盖安装；测试时设置、观看记录和搜索历史保留。
- 第三方站点和线路的可用性取决于各站点。当前固定规则中的 `dalvdm` 与 `xfdmneo` 搜索未通过本轮抽样；其他来源也有个别线路失败或波动。请使用可用的来源与线路。
- 本次在 Android 9 实体电视和 Android 16 Google TV 模拟器做了短时真实播放与界面回归，没有整集播放或所有来源的稳定性保证。
