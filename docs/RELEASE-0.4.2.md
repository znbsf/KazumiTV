# KazumiTV 0.4.2

本版集中修复原有电视操作体验。个人电视、频道、EPG、LCN等新功能不包含在本版（#2）。版本0.4.2+20392，三ABI versionCode为203921/203922/203924。

## 修复范围

- #1：关于、反馈、更新入口指向当前KazumiTV项目，保留上游致谢和开源许可。
- #3：设置滑条左右调值、上下离开；弹幕字号整数步长和透明度百分比步长可逆；原播放器保留左右seek语义。
- #4：输入框导航与编辑分离，确认后打开输入法，Back收起、取消恢复焦点。
- #5：统一主题与ColorScheme，遥控器可选色板；深色OLED选项使用纯黑背景，修复浅色播放器图标对比度，不承诺防烧屏。
- #6：修复设置分类栏、子菜单、长说明和缓存取消的焦点导航；播放器读取已保存的操作按键。
- #8原播放器部分：数字快捷角标默认显示，可隐藏且不影响原数字快捷操作；不包含新频道数字选台。

## 验证与边界

正式版生产源码相对已验收候选只变更版本元数据。候选完成846项全量测试及代表性Android TV/模拟器遥控回归，包含独立弹幕7项、播放弹幕5项、时间偏移、输入法Back、缓存取消、长说明、主题/OLED、按键保存与实际消费。正式版846项全量测试、静态0错误0警告58 info、三ABI构建签名和ARMv7保数据升级smoke均已通过；[CI检查与三ABI构建](https://github.com/znbsf/KazumiTV/actions/runs/38404754840)全部成功。

没有把所有控件调用点、所有业务分支或所有网站声明为实测通过。搜索双范围、自定义定时器有自动化覆盖；登录、同步、评论、建房等未做真实业务操作。ARM64/x86_64正式包只做构建与产物验证，无实机验收结论。

#7：保留已有来源验证码流程；固定上游的非2xx验证页处理、成功/取消/超时仲裁已继承。网站差异、多阶段挑战、API/章节验证与Cookie/UA传播仍有边界，未做全站验证码验收。真实验证码兼容继续跟踪，不保证所有来源可用。
