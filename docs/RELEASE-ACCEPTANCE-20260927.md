## 放行依据

1. 修复“热门”离开 LazyRow 后从收藏向右请求未挂载焦点导致的崩溃。生产代码先滚动并等待布局附着，后续按键或离页取消旧导航；统筹检查补丁，未用吞异常代替实际移动。
2. 最终包 229 单测零失败/错误，Lint/构建通过。修复任务在 5570 上完成导航边界六项、原首页六项及 baimao 第12集短实播，位置 9575→69530 ms。
3. 独立 UI 任务在自有 5584 核对设备安装包与最终哈希相同。原失败路径两次均回到可见热门而无崩溃，分类末端、普通左右、详情返回原卡片及再次进入通过。历史页为空，验证的是页面返回焦点；受控 `history_return` 也通过，不将此写成最终包真实历史条目续播实测。
4. 独立导航 instrumentation 六项全过，日志没有新增应用崩溃。两任务各自四项存储恢复核对一致，自有模拟器已关闭且保留数据；未操作当前无法连接的旧电视。
5. 同一播放实现此前在 Android 9 电视和 Android 16 模拟器的换线、换源、选集、历史/最近观看路径及受控恢复证据，按原构建保留，不迁移为新包已全量重测。
