# KazumiTV 0.4.3

本版纳入已合并并验证的稳定修复和播放 INFO，不包含个人电视、频道/EPG、AV1 实验或新的解码恢复功能。版本 0.4.3+20393，三 ABI versionCode 为 203931/203932/203934。

## 更新

- #9 / PR #10：详情和播放页显式换源，确认来源/集数并保留既有恢复逻辑。
- #11 / PR #12：API 9 sourceTemplate 规则兼容、重复进入设置的导航、控制栏 hover，以及 WebView load/parser 超时与卡住后的有限清理。
- PR #13：精简播放 INFO 卡片和遥控焦点恢复；限流器改用单调时钟并在定时器唤醒后复核实际请求间隔。
- PR #14：启动操作提示可聚焦，防止陈旧 SyncPlay 重连操作；收藏同步完成后聚焦关闭；首页首次加载失败可用方向键进入重试。

## 验证与边界

程序基线 127ecb3d1b98aea781eab44b7ced038cf11d26f0 的检查测试和三 ABI 候选构建全部通过。代表性模拟器和 Android 9 ARMv7 独立候选验收已记录；本次版本提交只修改版本与发布文档。正式签名、升级和公开附件验证以最终发布回执为准，不将候选 CI 包当作正式附件。

真实账号同步、自然发生的首次首页失败、全部站点/验证码和完整搜索链路未全测。已有累计播放记录不等于单源整集音画同步验收；ARM64/x86_64 不宣称实机通过。WebView init 永不返回及底层资源最终释放不在保证范围。保持既有电视 mediacodec_embed 默认，未宣称修复所有 AV1 或硬件解码兼容问题。
