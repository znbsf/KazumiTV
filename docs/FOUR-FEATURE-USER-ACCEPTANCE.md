# 四项功能人工验收（独立候选包）

这个包用于验收，不能替代正式版。名称 **KazumiTV-CI**，包名 `com.znbsf.kazumi.fluttertv.candidate`，与正式版 `com.znbsf.kazumi.fluttertv` 隔离。首次进入是独立数据目录，不会继承正式版收藏、历史或规则；不要清除、卸载或覆盖正式版，也不需要迁移私人数据。

## 下载与安装

从本次集成草稿 PR 的 **TV checks and candidate APKs** 成功运行中下载 `tv-candidate-armeabi-v7a-<SHA>` 附件（GitHub 可能要求登录，保留14天）。解压后只安装 `app-armeabi-v7a-tv-release.apk`；已验电视为 Android 9 ARMv7，选这个包。手机只使用浏览器，不安装电视APK。其他架构的附件不需要下载。

同一附件内 `armeabi-v7a.json` 是构建回执，记录精确源码 SHA、APK SHA256、包名和签名；以该回执及最终交付消息给出的校验值为准。这里的源码 SHA 可能是 GitHub PR 合并测试提交，与分支 head 不同，不能混用。

可通过电视现有文件管理器/USB安装；若用已授权ADB，先确认电视身份再执行 `adb -s <已确认电视地址> install -r app-armeabi-v7a-tv-release.apk`。若提示签名不一致，停止并反馈，不卸载已有应用或清数据。此包使用CI测试签名，版本文字 `0.4.0-ci` 是既有CI标识，并非正式升级或降级。

## 约10分钟，按顺序确认

1. **扫码与中文输入**：电视和手机接入同一家庭Wi-Fi；打开候选包搜索页的“手机输入”。手机扫码，输入 `命运之夜 测试中文` 并发送。电视应立即回显完全相同的文字；遥控确认“搜索”后应使用该关键词。另开一轮，Back退出弹窗，再在手机刷新旧链接，应无法继续提交；重开应得到新链接。等3分钟应提示过期。若连不上，记录两端网络/二维码中的地址即可，不修改防火墙、端口转发或VPN权限。
2. **跨番首次自动选源和失败退路**：在候选包“规则管理”加载你原本愿意使用的公开规则，无需账户或正式版数据。选作品A，在详情“源健康”查看进度、结果层级、时间和规则版本；可取消并返回。开启“首次播放自动选源”，对无历史的作品A首次播放。再选不同作品B首次播放，确认重新匹配B而不是沿用A。若没有可靠候选/源失败，应能明确手动换源，不能一直重试或自动破解验证码。一部一集成功只代表该次结果。
3. **电视实际声画**：选择你有权播放、含清晰对白或拍手/关门瞬间的短片段，电视扬声器以舒适低音量播放。观察口型/拍手与声音是否明显错开；记录大致提前还是滞后。依次测试正常播放30秒、快进/后退、暂停5秒再恢复；兼容恢复若出现，确认后再观察。先用1.0倍速，必要时补1.25倍速。正常和异常都记录片名、集数、时间点、源、解码模式与操作。不要只凭屏幕录像的音画偏移判播放器故障；采集链路本身可能有偏移。
4. **首页保留**：首次首页出现内容后退出重开，确认已有内容先出现、更新时间可见，手动刷新可达。自然发生网络失败时应保留旧内容并提示失败；不需要为了本次验收更改路由器或系统网络。

反馈只需：`项目 / 通过或异常 / 作品与时间点 / 操作 / 看到或听到什么`。扫码地址可私下提供，不必公开完整会话链接。完成后退出候选包，继续使用原正式版。保留一个当前候选包即可；此前内部FeatureQA/RecoveryQA不属于这次用户下载包，不必安装。

## 已通过与尚未证明

本地固定生产源码通过955项测试；Android 9电视和API36模拟器已验证受控恢复、首页失败保留、二维码回显/退出/到期、受控规则的真实首帧探测与取消。详细身份及证据见 [当前状态](PROJECT-STATUS.md)。本清单重点补真实手机Wi-Fi、生产搜索确认链路、不同作品/真实规则及实际电视扬声器体验。

公开站点的主机HTTP分层测试与App WebView/播放器探测分别记录在 [源健康记录](SOURCE-HEALTH-IMPLEMENTATION-20261017.md)。不要将HTTP200、页面可解析或录制文件有声音等同于首帧、全站可用或真实扬声器同步通过。最终CI候选包仍需本清单验收；此前隔离入口的成功不自动证明该APK全部流程通过。
