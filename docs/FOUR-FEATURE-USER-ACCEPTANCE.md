# 四项功能人工验收（独立候选包）

本轮整改候选名称 **KazumiTV-QA5**，包名 `com.znbsf.kazumi.fluttertv.fiveqa`，与正式版及旧 QA4 隔离。下载地址须以本轮成功 CI 的交付记录为准，旧 QA4 不包含这些修复。首次进入是独立数据目录，不会继承收藏、历史或规则；不要清除、卸载或覆盖正式版及旧候选，也不需要迁移私人数据。

## 下载与安装

从本次集成草稿 PR 的 **TV checks and candidate APKs** 成功运行中下载 `tv-four-feature-qa-armeabi-v7a-<SHA>` 附件（GitHub 可能要求登录，保留14天）。解压后只安装 `app-armeabi-v7a-tv-release.apk`；已验电视为 Android 9 ARMv7，选这个包。手机只使用浏览器，不安装电视APK。其他架构的附件不需要下载。

同一附件内 `armeabi-v7a.json` 是构建回执，记录精确源码 SHA、APK SHA256、包名和签名；以该回执及最终交付消息给出的校验值为准。这里的源码 SHA 可能是 GitHub PR 合并测试提交，与分支 head 不同，不能混用。

可通过电视现有文件管理器/USB安装；若用已授权ADB，先确认电视身份再执行 `adb -s <已确认电视地址> install -r app-armeabi-v7a-tv-release.apk`。若提示签名不一致，停止并反馈，不卸载已有应用或清数据。此包使用CI测试签名，版本文字 `0.4.3-qa5` 是本次验收标识，并非正式升级或降级。本轮没有代为安装到正在使用中的电视。

## 约10分钟，按顺序确认

手机键盘目前是**本次草稿替换**模式：所有普通字段的已有文本均不回传手机，手机新输入整体替换电视草稿，不追加到光标位置，也不能在手机直接编辑原文。切换字段会清空手机草稿，旧目标请求被拒绝，不会把上一字段文字自动覆盖到新字段。敏感字段完全禁用。完整光标编辑、标准遥控与长期配对另行分阶段实现，当前不扩大远程读取权限。

1. **应用级临时手机键盘（最新候选需新包）**：旧一次性搜索不再代表完成。显式开启连接，扫码或手打完整 URL，返回后按 OK 打开搜索框；多次输入中文、修改、清空和确认，确认后只保存文本，TV 另点搜索。切到规则 URL 编辑仍用同一手机页；DPAD 路过、编辑框退出、敏感字段均不得接收。测试慢请求后切字段、中文组合期间切字段、重复提交、网络中断与恢复；断开按钮和返回焦点应可达。闲置 10 分钟或应用进入后台连接应停止，重新开启需新会话。不得改防火墙、转发或 VPN 权限来掩盖实际 LAN 不可达。详见 issue15 原记录；长期配对和大遥控面板当前仅设计。
2. **成功记录复用与手动退路**：在候选包加载愿意使用的公开规则。先在没有成功记录时点“开始观看”，应直接进入手动选源，不自行搜索、健康探测或试播。然后在作品 A 详情显式进入“源健康”并点“开始检测”；记录可遥控逐条滚动、按 OK 看详情、返回原条目。获得成功记录后，开启“使用成功记录开始观看”和“将成功记录用于所有番剧”，再打开作品 B：只尝试一个记录源，重新匹配 B 的资源，不能沿用 A 的播放地址。记录源失败应回手动选择，不轮询未测规则；关闭全局开关后 B 不借用 A 的记录。单剧手选偏好只有存在成功记录时才优先。历史成功不会因一天后自动删除，详情保留最近尝试和历史成功；一部一集成功不保证全站可用。
3. **电视实际声画**：选择你有权播放、含清晰对白或拍手/关门瞬间的短片段，电视扬声器以舒适低音量播放。观察口型/拍手与声音是否明显错开；记录大致提前还是滞后。依次测试正常播放30秒、快进/后退、暂停5秒再恢复；兼容恢复若出现，确认后再观察。先用1.0倍速，必要时补1.25倍速。正常和异常都记录片名、集数、时间点、源、解码模式与操作。不要只凭屏幕录像的音画偏移判播放器故障；采集链路本身可能有偏移。
4. **首页保留**：首次首页出现内容后退出重开，确认已有内容先出现、更新时间可见，手动刷新可达。自然发生网络失败时应保留旧内容并提示失败；不需要为了本次验收更改路由器或系统网络。

反馈只需：`项目 / 通过或异常 / 作品与时间点 / 操作 / 看到或听到什么`。扫码地址可私下提供，不必公开完整会话链接。完成后退出候选包，继续使用原正式版。保留一个当前候选包即可；此前内部FeatureQA/RecoveryQA不属于这次用户下载包，不必安装。
