# KazumiTV v0.3.3

电视播放与首页更新。

## 更新内容

- 改进来源切换、选集、进度续播，以及从历史和首页最近观看返回播放的遥控路径。
- 更新电视首页：单行导航、六列节目卡片、最近观看入口，并改善详情返回后的焦点与位置恢复。
- 修复分类行滚动后，从收藏向右回到热门时可能退出应用的问题。
- 改进播放器控制、网络错误提示和有限重试/取消路径。

## 安装与验证范围

- Android 7.0 / API24 及以上；包名 `com.znbsf.kazumi.compose.tv`，版本 `0.3.3` / code53。
- 延续公开 `v0.3.3-preview.6` 的签名，可直接覆盖安装。集成候选的覆盖升级保数据测试通过；最终包的四项存储恢复核对通过。
- 最终包通过 229 项单测、Lint、导航/首页回归与短时真实播放；离屏分类焦点修复由另一任务在独立 Android 16 模拟器上复测通过。
- Android 9 实体电视完成过此前集成候选的播放与首页测试；最终焦点修复未在该电视重测。内部声画录制来自修复前候选的 Android 16 模拟器，不代表电视扬声器或精确口型同步已验证。
- 固定规则中的 `dalvdm` 与 `xfdmneo` 搜索未通过本轮抽样，其他来源也有个别线路失败或波动。验证码、网站改版和网络差异仍可能影响使用。
- 按计划不做整集测试；正式发布不等于所有来源稳定或完整迁移完成。详细范围见仓库验收记录与逐源矩阵。
