# KazumiTV 0.4.1

正式 TV 包：`com.znbsf.kazumi.fluttertv`，版本 **0.4.1+20338**。源码与标签 `v0.4.1` 精确对应 `9f5fe263b4a92271b5938a6b6294e43b8cc94f75`。后续主线文档提交不改变这批APK的源码。

## 改动

- 修复取消/切集/退出时迟到弹幕请求污染状态，旧对话框取消不再影响新加载。
- 恢复已有合法弹幕应用认证的正常构建注入，自动匹配、手动搜索与真实弹幕已验证；私有配置源文件和构建凭据不随源码或附件发布。
- 修复历史记录播放入口，保留播放恢复、seek及升级数据保护。
- 时间线改小海报：实测1080p电视两列三完整行，16sp标题、评分同排、紧凑页头与完整遥控焦点。
- 首页使用400px图源，修复200px缩略图放大造成的模糊；详情保留实际已显示封面，小卡片继续使用缩略图，显示缓存仍限24张/32MiB。
